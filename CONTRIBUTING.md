# Contributing to html2rss

Thanks for helping. Pick the right channel first:

- **Questions and ideas:** start a [GitHub Discussion](https://github.com/orgs/html2rss/discussions).
- **Bugs and feature requests:** open an issue with the matching form. Blank issues are disabled.
- **Code, config, or docs changes:** open a pull request.

## Pull requests

- Every change lands through a pull request. Do not push directly to a default branch.
- Use a [Conventional Commit](https://www.conventionalcommits.org/) title, such as `fix:`, `feat:`, `docs:`, or `chore:`.
- Keep each pull request to one repository and one logical change.
- Fill in the pull request template: what changed, why, and the validation commands you ran.

## Setup and checks

Each repository documents its own setup, tests, and lint gates in its `README.md` and `AGENTS.md`. Follow the one in the repository you are changing:

- [html2rss](https://github.com/html2rss/html2rss#readme)
- [html2rss-web](https://github.com/html2rss/html2rss-web#readme)
- [html2rss-configs](https://github.com/html2rss/html2rss-configs#readme)
- [html2rss.github.io](https://github.com/html2rss/html2rss.github.io#readme)
- [botasaurus-scrape-api](https://github.com/html2rss/botasaurus-scrape-api#readme)

## Conduct and security

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). Report security issues privately as described in [SECURITY.md](SECURITY.md), never in public issues.
