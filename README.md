# html2rss organization

This repository holds the html2rss organization profile and the default community health files for all html2rss repositories.

- [profile/README.md](profile/README.md): organization profile shown on the organization page
- [CONTRIBUTING.md](CONTRIBUTING.md): how to contribute
- [SECURITY.md](SECURITY.md): how to report security issues
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): community standards
- [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/): issue forms
- [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md): pull request template

A repository's own copy of any of these files overrides the default.

Changes land via pull request.
