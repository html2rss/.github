Most websites have abandoned RSS feeds, leaving users without control over their
content consumption. We're building the infrastructure to bring RSS back to every
website on the internet.

- [Community Forum](https://github.com/orgs/html2rss/discussions) - Discussions, Q&A, and community support
- [Kanban Board](https://github.com/orgs/html2rss/projects/3/views/1) - Development progress and roadmap
- [Project Website](https://html2rss.github.io/) - Documentation, tutorials, and guides

## 🔧 Technology Stack

- **Backend**: Ruby, Roda (lightweight web framework)
- **Testing**: RSpec, VCR for HTTP mocking
- **Deployment**: Docker-ready, configurable for any environment
- **Monitoring**: Built-in health checks and performance metrics
